# 启动器图标尺寸与拖动排序

## 需求与验收

1. 圆弧和长条二级菜单的图标与同页主圆环普通图标等大。启用或隐藏项目名称时，设置页预览和实际轮盘使用同一套尺寸规则。
2. 在「启动器 → 编辑项目」中，把图标拖到同层的另一项上时，中间项目沿圆环让位。松手后保存所见的顺序，拖出有效区域或取消时恢复原位。
3. 带二级菜单的主环入口可以作为一组拖动。打开二级菜单编辑后，可独立拖动该组子项，圆弧和长条都支持。

## 开发进度

- 已完成。主环和二级菜单现在共用主环图标尺寸，圆弧和长条均覆盖项目名称开启与关闭的情况。
- 已完成。拖动时生成临时顺序，目标与沿途项目会平滑让位。松手后才写入 `launcherItems`，取消或离开目标会恢复原顺序。
- 已完成。长条中的主环入口支持整组拖动。进入二级菜单编辑后，子项使用带父级作用域的拖放数据独立排序。
- 已验证。启动器相关 31 项和 ReleaseTools 的 24 项测试全部通过。已离屏检查圆弧和长条预览，并确认临时应用包包含拖放类型声明。
- 最终全量回归中，两个既有焦点测试因锁屏启用系统安全输入而失败。排除这两项后，296 项通过，2 项按既有条件跳过。
- 待真机交互验收。开发时桌面处于锁屏状态，鼠标拖动动画、取消拖动和放下保存尚待在解锁后的设置窗口确认。

## 实现记录

- `LauncherTileLayout` 提供主环尺寸基准，实际轮盘、设置页圆环和长条共用该基准。
- 使用应用内专用拖放类型传递来源和父级作用域，避免同名项目在主环和二级菜单之间误排序。
- 圆环预览使用稳定槽位接收拖放，并通过临时投影顺序驱动位置动画。持久化回调只在有效放下时执行。
