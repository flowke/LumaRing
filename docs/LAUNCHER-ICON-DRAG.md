# 启动器图标尺寸与拖动排序

## 需求与验收

1. 圆弧和长条二级菜单的图标与同页主圆环普通图标等大。启用或隐藏项目名称时，设置页预览和实际轮盘使用同一套尺寸规则。
2. 在「启动器 → 编辑项目」中，把图标拖到同层的另一项上，或拖到两个相邻项目之间的空隙时，其他项目沿圆环让位。在空隙松手时，图标插入这两个项目之间。松手后保存所见的顺序，拖出有效区域或取消时恢复原位。
3. 在左侧圆环中，直接拖动可见的二级菜单图标，只在同一组内重新排序，不必先打开右侧分组编辑。长条分组靠圆心处有独立的整组拖柄；圆弧分组使用主环上的分组图标。拖动分组时保留子项顺序，普通主环图标仍可直接拖动。
4. 主环按经过槽位更少的方向让位，顶部两侧的首尾槽位视为相邻。拖动项沿最短路径进入目标槽位，路径上的项目依次向空位移动一格，路径之外的图标保持原位。拖到同层项目之间时同样按这条规则插入。
5. 「编辑项目」与「圆环设置」共用同一条可拖动分隔线及面板宽度。拖动预览区域右缘改变左右栏比例；窄窗口自动改为上下布局。
6. 圆环预览依据当前实际显示的菜单和图标边界放大填充可用区域，不再为未显示的二级菜单位置预留空间。重排期间保持缩放不变，松手后再依据新顺序适配。
7. 长条分组拖柄保持小尺寸，靠近首个子图标。分组移到不同角度后，拖柄按图标的可见轮廓留出相同的间隙。显示项目名称时也为名称留出空间。
8. 长条轮廓应为悬停图标与高亮背景留出可见间距，斜向与末端位置也不能贴边；相邻分组仍保持连续且互不侵入。

## 实现记录

- `LauncherTileLayout` 提供主环尺寸基准，实际轮盘、设置页圆环和长条共用该基准。
- 使用编辑器内的拖动手势跟踪来源项目和父级。指针命中项目时使用该项目的槽位。指针在同层预览轨道的空隙内时，按轨道上的相邻项目计算插入位置。主环可沿两个方向跨过顶部，顺逆时针距离相同则沿用列表的插入方向。
- 圆环预览使用稳定槽位接收拖放，并通过临时投影顺序驱动位置动画。主环只沿源与目标之间的较短路径传递空位，首尾槽位相邻；距离相同时沿列表方向选边。持久化回调只在有效放下时执行。
- 设置页面以共享面板宽度和可拖动分隔线协调预览区、设置面板；圆环预览变换基于当前顺序的可见外框，拖动中的投影顺序复用同一变换。
- 子图标只接受同组子项排序；主环项目拖到长条图标或条内空隙时，落点是该分组的主环槽位。整组移动继续使用主环最短距离规则。
